# Wayflyer

> Wayflyer provides revenue-based financing for e-commerce businesses, and its Embedded Finance (Hosted Capital) API lets partner platforms offer Wayflyer funding to their merchants in-product: upload anonymized revenue data to generate indicative offers, render a CTA banner, and run the embedded (v5) or hosted (v4 legacy) funding application. Auth is a two-tier bearer-JWT model (partner token -> per-merchant company tokens, ~24h TTL). Production base URL https://api.wayflyer.com/financing/ with a full-parity sandbox at https://sandbox-api.wayflyer.com/financing/.

Generated by API Evangelist from the Wayflyer developer portal and the artifacts in this repository (no /llms.txt is published at docs.wayflyer.com; probed 2026-07-21, HTTP 404).

- [Embedded Finance API reference](https://docs.wayflyer.com/apis/embedded-finance-1-0-0/docs): OpenAPI 3.1, 27 operations — tokens, CTA, embedded/hosted applications, user/company details, documents, anonymized data upload
- [Embedded Finance Sandbox API reference](https://docs.wayflyer.com/apis/embedded-finance-sandbox-api-1/docs): sandbox twin plus application-state simulation endpoints
